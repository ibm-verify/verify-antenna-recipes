# IBM Verify Antenna Vault Agent Sync Recipe

This recipe contains two complementary IBM Verify Antenna recipes:

- `transmitter/` - converts IBM Verify application lifecycle events into SSF events with a Agent payload.
- `vault-receiver/` - consumes the Agent payload and synchronizes HashiCorp Vault entity aliases.

The folder follows the same recipe-oriented structure as the IBM Verify Antenna VIP recipe: component folders, each with its own `README.md`, `configs/js`, and recipe-specific scripts where applicable.

No lab scaffolding, generated templates, or standalone documentation bundles are included in this recipe package.
